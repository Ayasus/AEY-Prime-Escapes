# AEY Prime Escapes

A modern real estate website developed for **AEY Prime Escapes**. The system provides users with an easy way to browse properties, view property details, explore new developments, and access real estate services.

## Project Overview

AEY Prime Escapes is a web-based real estate platform designed to present available properties in an organized and user-friendly interface.

The website was developed using **React and Vite**, with **Supabase** prepared for database integration.

The project aims to provide a simple and modern online experience for users who want to explore real estate properties and related services.

## Features

- Property listing and browsing
- Property detail pages
- New developments section
- About page
- Real estate agents section
- My Reservations section
- Responsive website interface
- Modern and user-friendly design
- Supabase database integration
- Environment variable configuration for Supabase
